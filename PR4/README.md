# Semana 4 — Boceto y paleta de colores

- `boceto.png` / `boceto.svg`: wireframe de baja fidelidad del inicio, en escritorio y celular, con notas de diseño.
- `paleta_colores.css`: variables CSS de la marca (colores, tipografías, radios y sombra) y clases de ayuda (`.btn-principal`, `.tarjeta`…).
- `paleta.html`: página de muestra que lee las variables con `getComputedStyle`, así siempre muestra los colores reales del CSS.

## Idea de la paleta

Los colores salen de la cerveza misma:

| Variable | Color | Uso |
|---|---|---|
| `--ambar` | `#FFB100` | Lager dorada: fondos destacados |
| `--naranja` | `#FF6B4A` | IPA/Red Ale: botones y precios (llamado a la acción) |
| `--tinta` | `#2B1B12` | Stout: texto, header oscuro y footer |
| `--crema` | `#FFF8EA` | La espuma: fondo general |
| `--teal` | `#1FAE93` | Growlers, reciclaje y mensajes de éxito |
| `--purpura` | `#8B4FE3` | Club Cervecero (sensación premium) |

Tipografías: **Fredoka** (títulos redondeados y amistosos) + **Nunito** (texto).
