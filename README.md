# Desarrollo Web y Móvil — Craft & Beer 🍺

Proyecto del ramo construido semana a semana sobre una tienda de cerveza artesanal.

| Semana | Tema | Tecnologías |
|---|---|---|
| [1](Semana_1) | Sitio estático | HTML, CSS, Tailwind |
| [2](Semana_2) | Sitio dinámico con includes y formulario | PHP |
| [3](Semana_3) | Interacción: carrito, filtros, validación | JavaScript, localStorage |
| [4](Semana_4) | Boceto y paleta de colores | Wireframe, variables CSS |
| [5](Semana_5) | API GraphQL del catálogo | Node, Apollo Server, Mongoose, MongoDB |
| [6](Semana_6) | API REST de socios del club | Python, FastAPI, pymongo |
| [7](Semana_7) | Microservicios + API Gateway | FastAPI, httpx, asyncio |
| [8](Semana_8) | Seguridad y manejo de secretos | API keys, Bearer, Vault, Docker |
| [9](Semana_9) | Autenticación con cookies + despliegue | Auth service, cookies HttpOnly, nginx, Docker Compose |

Cada carpeta tiene su propio README con instrucciones para correrla.
